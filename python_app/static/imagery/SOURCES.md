## Download parameters

Source CDN URLs use the following public format, with the corresponding identifier from the table:

```text
https://images.unsplash.com/<identifier>?auto=format&fit=crop&fm=jpg&q=82&w=900
```

`hero.jpg` uses `w=1800`. The images were delivered as JPEG files by Unsplash; no local raster edits were applied. Each file was decoded and verified with Pillow. Normal responsive `object-fit: cover` presentation can be handled by the site's CSS.

For the wide hero, the astronaut is on the right-hand side; a left-side dark overlay keeps the title readable. The other images are intended for CSS-cropped portrait cards and a membership collage.
